# 场馆的温湿度控制

[[toc]]

<br>
<br>

## 🎯 项目目标

实现对阅览室人数的监测和自动控制，提高阅览室的管理效率和安全性。

<br>
<br>

## 📖 原理方法

利用温湿度传感器采集阅览室内的温湿度数据，通过实验箱将数据传输到创趣物联网平台。根据预设定的温湿度阈值，系统自动控制电扇等设备的开关，实现对环境温湿度的调节。

<br>
<br>
